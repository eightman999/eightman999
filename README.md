## 🧑‍💻 About Me

I'm an **information engineering student in Japan** working across **AI systems, local LLMs, developer tooling, and experimental software**.

My projects tend to start with a practical or slightly strange question, then grow into an implementation, an experiment, and finally something measurable and reproducible.

- 🧠 Persistent / distributed AI architecture and cognitive systems
- 🧪 Local LLM training, evaluation, tokenization, and reproducible benchmarking
- 🤖 Agentic development workflows with coding agents, CI, tests, and evidence-driven review
- 💻 macOS / Android / Web applications and developer tools
- 🎮 HOI4 modding, simulation tools, and software-culture preservation
- 🧰 Rust · Python · Swift · Kotlin / Java · C / C++ · C# · TypeScript / JavaScript

日本語では、AI・ローカルLLM・開発ツール・アプリ・MODなどを横断して、**「気になったものを実際に動くところまで作る」**ことをしています。

## 🔬 Current Focus

| Project | What it is |
|---|---|
| 🧬 **[Kamimusuhi / かみむすび](https://github.com/eightman999/kamimusuhi)** | Experimental architecture for a persistent, distributed, developing artificial cognitive individual whose continuity is not tied to one model or machine. |
| 🧪 **[YLSB](https://github.com/eightman999/YLSB)** | Reproducible benchmark for complete local-LLM configurations: model, quant, runtime, GPU, context, KV cache, split, MTP and more. |

These projects share a common theme: **build the system, measure the system, keep the evidence, and make the next experiment easier than the previous one.**

## 🧭 How I Work

```text
idea / problem
    ↓
survey & design
    ↓
prototype
    ↓
measurement / benchmark
    ↓
failure analysis
    ↓
reproducible artifact
    ↓
next experiment
```

I use AI coding agents heavily, but try to keep **claims separate from measurements**: CI, test results, raw outputs, hashes, experiment manifests, and failure records matter more than "it seems to work".

I also run local experiments across **Apple Silicon and CUDA systems**, including mixed-generation NVIDIA GPUs, so hardware constraints are treated as part of the research rather than an afterthought.
